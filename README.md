# API Testing Project

Repository ini berisi dokumentasi dan hasil pengujian API menggunakan Postman dan Newman.

## 📄 Dokumentasi

Hasil testing dalam bentuk file `.html` disimpan di dalam folder ini.  
Untuk melihat tampilan dokumentasi API testing secara utuh, silakan **download file `.html` terlebih dahulu** dan buka melalui browser di komputer kamu.  
Jika dibuka langsung di GitHub, tampilan mungkin tidak sempurna karena keterbatasan render HTML.

## 🛠 Tools yang Digunakan

- [Postman](https://www.postman.com/)
- [Newman](https://www.npmjs.com/package/newman)
- [Git](https://git-scm.com/)
- [GitHub](https://github.com/helloiamfeli/apitesting)
